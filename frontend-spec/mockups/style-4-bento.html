移动端设计要点
A app-bar 紧凑型：刷新按钮 + 头像，去掉桌面端的宽 padding
B bento 2 列网格：路径/文件类型卡跨 2 列，其余 1:1 等分
C history-item：去掉 meta 行，只保留 query + 日期缩写（2h / 3d / 1w）
D input-box：搜索框 + 按钮 + 纯文字模式 pill（无图标）
E tab-bar 浮动：毛玻璃白底 + 大圆角浮起，替代桌面 activity-bar
Bento 网格规格
桌面：4 列 × 2 行，路径卡和类型卡 span-2，形成非对称节奏
移动：2 列，wide 卡 span-2，其余 1:1
内卡圆角：12px（桌面）/ 10px（移动）
live 卡：绿色渐变背景 + pulse 动画圆点
视觉语言
浅灰底 #F5F5F7 让白色卡片浮起
Soft shadow 0 4px 12px rgba(0,0,0,0.06)
大圆角 20-24px 外卡，12px 内卡
等宽字体 JetBrains Mono 用于数据值
毛玻璃 backdrop-filter 用于 app-bar / tab-bar
