# 提示词写法

想法：{画面想法}　比例：{比例}

## 结构（按这个顺序写，用逗号或短句连接）
1. **主体**：谁 / 什么，外观细节，在做什么
2. **场景**：在哪里，背景有什么
3. **构图**：景别（特写 / 半身 / 全景）、视角（平视 / 俯拍 / 仰拍）、主体位置、留白
4. **光线**：自然光 / 逆光 / 柔光箱 / 黄昏 / 霓虹……
5. **风格与媒介**：摄影、扁平插画、3D 渲染、水彩、像素风……（可参考 references/style-vocabulary.md）
6. **色彩**：主色、配色、整体冷暖
7. **质感与细节**：材质、景深、颗粒感
8. **比例**：{比例}

## 方向
方向没定时，先给 2–4 个方向，每个一行：方向名 + 一句话画面 + 适合的场景，让用户挑。

## 写法要点
- 具体胜过抽象：「清晨的薄雾里，一只橘猫趴在木窗台上」好过「温馨的猫」。
- 一张图只表达一个重点，元素不要堆太多。
- 画面里的文字写成「文字内容为：“…”」，越短越好，生成后检查拼写。
- 不写真实人物姓名、他人商标或受版权保护的角色名，除非用户确认有权使用。
- 不要堆砌「超高清、杰作、8K」这类空词，效果有限。
- 改图一次只改一两处，并记录这次改了什么。

## 交付格式
```
方向：…
提示词：…
比例：…
改动记录：第 N 版 —— 改了什么
```

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
