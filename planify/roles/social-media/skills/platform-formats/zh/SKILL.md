# 平台格式

平台：{平台}　内容：{内容}

## 步骤
1. 找到下面对应的平台要点；没有列出的平台，先问用户该平台的常见格式。
2. 同一个内容换平台时，重写开头和结构，不只是改长度。
3. 每篇输出：标题（3 个备选）、正文、标签、配图需求、建议发布时间、注意事项。
4. 各平台规则会变，字数等限制以平台当前说明为准；拿不准时提醒用户核对。

## 平台要点（经验值）
- **小红书**：标题短、有具体利益点或数字；正文分段、口语化、像朋友分享，可用少量表情符号；封面图决定点击，竖版 3:4；文末 3–8 个话题标签。
- **公众号**：标题信息量大但不标题党；开头 3 行讲清「为什么值得读」；小标题分段、段落短；封面横版；文末一个明确的行动（关注、留言、阅读原文）。
- **抖音 / 视频号 / 快手**：写成竖屏短视频脚本（可用「分镜脚本」技能）；前 3 秒是关键；文案描述 1–2 句 + 2–5 个话题。
- **B 站**：中长视频，标题和封面要说清内容；简介写时间轴章节；语气可以更轻松、更有梗。
- **微博 / X**：短，一条一个观点；重要信息放前面；话题 1–2 个；长内容拆成串。
- **LinkedIn**：专业但有人味；第一行抓注意力（显示「更多」之前的部分）；分短段；3–5 个标签。
- **Instagram**：图片优先（1:1、4:5 或 9:16）；文案前一行最重要；标签放末尾。

## 共同规则
- 不夸大、不误导；广告和合作要按平台要求标注。
- 不搬运他人内容，图片音乐注意授权。
- 只准备草稿；发布由用户自己操作。

## 使用边界

优先使用已有信息；用户的数量、格式和任务范围优先于本文默认模板。工具权限、主目录/附加只读、Plan 模式与预算以当次实际能力为准；不换工具规避拒绝。这里只给工作方法，不授权写入、命令、付费、发送、提交或发布；未执行/验证的步骤如实标明。
