# 调研报告

问题：{调研问题}
用途：{用途}

## 步骤
1. **拆问题**：把大问题拆成 3–6 个子问题，说明先查哪个、为什么。
2. **找来源**：优先一手来源（官方、原始数据、论文、公告），记下日期；联网遵守本次实际权限和审批结果。资料按「资料整理」技能记笔记。
3. **核对**：关键事实尽量找两个独立来源；来源之间矛盾时都列出来。
4. **综合**：每个子问题写出答案，标明事实 / 推断 / 观点。
5. **结论**：回到用途，给出结论、把握程度和建议。
6. **局限**：写清没查到的、可能过时的、样本有限的地方。

## 模板

```
# <调研主题>
日期：…　范围：…

## 结论摘要（3–5 条）

## 子问题
### 1. <子问题>
- 事实：… [1][2]
- 推断：…（依据：…）
- 不同观点：…

## 建议

## 局限与待补充

## 来源
[1] 作者 / 机构.《标题》. 发布日期. 链接或出处. 查看日期
```

## 报告类型（做行业研究、写或读研报时加用）

**行业研究**（任何行业）：
- 先列出这个行业自己的核心指标再找数据，例如零售看同店增长和坪效，SaaS 看 ARR 和净留存，制造看产能利用率和毛利率，医药看管线阶段和获批数；不确定时写明选这些指标的理由。
- 必含：市场规模（口径、年份、增速，区分总量和可触达部分）、产业链上中下游和利润分布、竞争格局（主要参与者、份额或集中度）、驱动与制约因素、政策监管、技术与商业模式变化。
- 来源优先统计局、主管部门、行业协会、上市公司年报和招股书；咨询机构的数字注明机构和口径，不同机构数字差异大时并列。

**写研报**（行业或公司）在模板基础上：
- 开头「核心观点」3–5 条，每条带关键数字和把握程度。
- 「盈利预测」表：收入、归母净利润、EPS、增速，近 2 年实际加未来 3 年预测，标明哪些是自己的假设、哪些引自机构一致预期。
- 「估值」：写明方法（PE / PB / EV/EBITDA / DCF）、关键参数和可比公司表，表下写数据截止日。
- 「风险提示」单独一节，至少 3 条会让结论失效的具体风险。
- 末尾写「本报告由 AI 助手整理，仅供研究参考，不构成投资建议」，不给买卖指令。

**读研报**（整理、比较别人的研报）：
- 每份提取机构、作者、发布日期、评级、目标价、核心假设、关键预测和主要风险；没写的标「未提及」，不替它补全。
- 多份放一张对比表，标出评级、目标价和假设的分歧，并说明分歧来自哪个假设。
- 发布超过 6 个月或之后有新财报的预测标「可能过期」；关键事实回到公司公告核对，核对不了的标「仅来源于研报」。

## 规则
- 不编造来源、数字和链接；找不到就写「未找到」。
- 引用原文要短，并注明出处。
- 写入遵守本次实际权限和审批结果；报告按角色规范的交付规则保存和命名。

## Word 报告、模板与修订
1. 用户要求 Word 时，用 office_create 写真正的标题层级、段落、表格、题注与来源；按需要设置页眉页脚、页码和目录域（注明打开后更新），不要仅改扩展名。原程序合同的 Markdown 报告仍保留，用户明确的格式与交付路径按当前有效合同处理。
2. 模板：有 office_template_fields / office_template_fill 时先用它们填字段；没有时用 office_inspect 找占位符与表区域，再用 office_edit 替换；核对跨 run 字段与循环表格行，保留样式和页眉页脚，不猜字段值。
3. 改已有 Word 前读取最新 revision、结构与书签，先建检查点；要求修订模式时写真正修订（作者 Pi Bot · 当前 Bot 名）与批注，可按书签替换。接受或拒绝修订只按本次要求，不自动清空所有修订。
4. 用 office_validate 核对标题、表头和关系，必要时 office_render 看版式；报告未验证项。可用工具不支持时说明阻塞，不重建外部文件冒充保真。
5. 群里需要 PPT 时将结论、来源映射和待确认项交给演示设计师。
