# ADR-0016: 对话页技能直发——发送按钮复合化与最近技能菜单

对话 tab 的发送按钮改为复合按钮（主键「发送」+ caret 菜单），让用户在提问前选择技能；菜单第 1 项「选择技能…」弹出技能选择对话框，其下为最近使用的 ≤3 个技能；须先输入问题才能选技能，点选技能后立即发送。2026-09-08 决议。术语定义见 CONTEXT.md（对话技能候选 / 最近技能 / 对话技能直发）。

## Context

技能此前只有一个入口：files 页多选文件后的工具箱（ADR-0008 技能会话链路）。纯提问场景（无文件）想用技能引导 AI 时没有入口——用户只能先开聊再指望 AI 自主 load_skill。用户要求在对话页输入框上直接提供技能选择。

## Decision

### 1. 对话技能候选 = 全部启用技能，与工具箱白名单独立

菜单与对话框的候选集合 = `/api/skills/manage` 过滤 `enabled && !deleted`。`context_menu` 白名单是 files 页文件场景的显隐开关，不绑架对话场景。

- **否决「复用工具箱白名单（GET /api/skills）」**：用户把技能移出工具箱（不想占用文件右键菜单）时会误伤对话入口，两个不相干场景被同一开关耦合。

### 2. 最近技能 = 用户显式选择的 ≤3 个，前端 localStorage 记账

- 只记**用户主动点选**（对话页菜单/对话框、files 工具箱），AI 在对话中自主 load_skill 不记账；按最后选择时间倒序去重，菜单最多展示 3 个。
- 存浏览器 localStorage：UI 便利性数据，与 PWA 其他本地偏好同级。
- **否决「存 skills_config.json sidecar」**：配置档案语义是「用户显式设置」，混入使用历史会破坏稀疏覆盖模型；且 files 工具箱路径也要额外调 API 记账。接受换浏览器/设备不同步。

### 3. 选中技能发到当前会话，不强制新建

点选技能 = 立即把问题发往**当前会话**，保持对话连续；仅 initial 态（无当前会话）时新建——此时首条消息带 `[调用技能:]` 标记，按既有身份推导自然成为技能会话（提取式引文生效）。技能只作本条消息的引导，不改变已有会话身份。

- **否决「总是新建技能会话」（工具箱路径语义）**：打断当前对话的代价大于收益；技能引导混入上文的可控性交给用户（是用户在自己对话流里主动选的）。工具箱路径保持「总是新建」不变——它是文件批处理场景，无对话连续性诉求。

### 4. 消息信封复用工具箱格式

`[调用技能: name]` + `请先 load_skill("name") 加载技能，然后按技能指引处理。` + 用户问题原文（无文件清单段）。AI 侧零改动；用户气泡显示完整信封文本（与工具箱路径一致）。

- **否决「精简信封」（仅标记 + 问题）**：显式 load_skill 指引是工具箱路径验证过的可靠性保障，精简后引导强度变弱。

### 5. 交互形态

- 菜单结构：第 1 项固定「选择技能…」（弹技能选择对话框），其下为最近 ≤3 个技能（图标+名称）；无最近记录时只有第 1 项。点任意技能项 = 立即发送。
- 技能选择对话框**复用 skill-toolbox-dialog**，技能清单改为调用方传入（files 页传工具箱清单、对话页传全部启用清单），不再内嵌自取。
- 适用范围 = 对话页两处输入框（initial 态 + focus 态底部输入栏）。
- 可用条件：输入为空 → caret 禁用；流式中 → caret 随发送键隐藏（停止键独占）；主按钮始终为普通发送，行为不变。
- 失效处理：菜单渲染时最近列表与当前候选求交，停用/删除的技能静默消失（不清缓存，恢复启用后自然回来）；候选全空时 caret 不渲染，退化为普通发送按钮。
- 移动端：菜单向上弹出、菜单项与 caret 命中区 ≥44px；对话框沿用 toolbox 的 matchMedia 列表形态（1023px 断点），不引入全屏范式。

## Considered Options

- 工具箱白名单当对话候选——否决（§1，场景耦合）。
- 最近列表存后端 sidecar——否决（§2，污染配置语义）。
- 总是新建技能会话——否决（§3，打断对话连续）。
- 精简信封——否决（§4，引导强度）。
- 「预选技能」模式（caret 常可点、选后不发送、主键带技能标记）——否决（§5，违背「选择即发送」，且引入预选状态展示/取消的复杂度）。

## Consequences

- input-box 的 modes 分裂按钮机制扩展出第二种菜单形态（技能菜单），或对话页自建菜单层——实现选型，领域语义不变。
- 「最近技能」跨入口统一记账点收敛在 chat 发送路径与 files 工具箱提交路径两处（均经用户显式点选）。
- 技能会话身份推导逻辑不变（仍只看首条消息）；对话页直发到已有会话的技能消息不产生技能会话身份，其回答仍走 [N] 声明式引文。
