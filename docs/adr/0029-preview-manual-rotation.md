# ADR-0029: 预览期手动旋转图像

全屏图片查看器新增旋转钮：用户预览图像时一键顺时针 90° **像素级旋转落盘**，复用判向自动旋转（ADR-0017）的旋转与收尾管线。2026-09-20 决议。术语定义见 CONTEXT.md（手动旋转）。

## Context

判向自动旋转（ADR-0017）只覆盖**上传入口**且依赖视觉 API 可用，四类图像仍然歪着且无救济：存量图（功能上线前已在库）、手动拷贝进目录的图（判向明确不管）、视觉判向存疑未转的图（严格解析「宁可漏转」）、视觉 API 未配置时期的上传图。用户预览时看到歪图，只能出库用外部工具转正再拷回来。

需求原话「预览的时候可以对图像进行就地顺时针旋转」——「就地」存在两种读法，本 ADR 钉死语义。

## Decision

### 1. 落盘而非显示态

旋转 = PIL 像素级顺时针 90° + 同格式重编码写回原文件（直接复用 `image_orienter.rotate_image_inplace`，JPEG q95 / WebP q90 / PNG 无损，先内存编码后覆盖）。

- **否决「显示态 CSS 旋转」**：刷新/重开即还原，对歪图治标不治本；预览期想旋转的主因是自动判向漏转/存疑未转的**补救**，要的是文件转正。
- **否决「只写 EXIF Orientation」**：继承 ADR-0017 §3 结论（WebP/PNG 支持参差，视觉链路读原字节不看 EXIF）。
- 原件污染（重编码有损一代 + 无备份）与 ADR-0017 / ADR-0009 同类，项目已整体接受。

### 2. 入口 = 全屏查看器单入口，按 src 可旋转性显隐

`image-viewer`（被图像预览页内嵌原图、md 文档图片、日记面板三处复用）内解析 `src`：URL 为 `/api/preview/raw` 且扩展名 ∈ jpg/jpeg/png/webp（与 `ORIENTABLE_IMAGE_EXTS` 对齐）才显示旋转钮。

- 知识库图像文件（图像预览原图 / md 相对路径引用图 / 日记照片缩略图，三者均经 raw 端点服务）天然覆盖，**三个调用点零改动**。
- 文档内嵌图片（`/api/preview/asset`，ImageStore 提取产物）**排除**——重索引即被覆盖的派生产物，旋转无意义。
- gif/bmp/tiff 预览可见但不在四格式集，不显示按钮（与判向旋转、视觉解读同一集合）。

### 3. 无条件可用——不跟随判向旋转的开关与视觉配置

判向自动旋转要求 `VISION_AUTO_ROTATE` 开 + 已配视觉 API（判向本身要调模型）；手动旋转是纯像素操作，零 API 依赖，**任何配置下都可用**。

- **否决「跟随开关」**：用户显式点击的意图不应被自动功能的开关连坐。
- 未配视觉 API 时行为：只旋转 + 重索引，视觉解读维持占位/缺失现状（与既有「未配置视觉 API」语义一致）。

### 4. 不弹确认，点即转

连点累加角度（3 次 = 270°）是预期操作流，逐次确认破坏性最大。反馈链：按钮 loading 防连点 + 失败内联红态 2s；成功 toast 经既有 `image_rotated` SSE 链（SSE payload 新增 `manual` 标志，app-bar 据此区分措辞：手动「已旋转」vs 自动「已自动旋转」）。

### 5. 索引联动 = 完整复用 ADR-0017 §6 收尾

旋转落盘后：删除 vision_queue 中该图残留行（防歪图白转写）→ FileWatcher 自然重建 → PIL 重编码剥掉全部元数据段 → 内容指纹变化 + 旧视觉解读随元数据消失 → 重新入队转写（正向图）。零新增编排。

代价（与判向旋转相同）：已配视觉 API 的库，每转一次重花一次转写调用；重转写期间旧解读短暂缺失。

## Considered Options

- 显示态 CSS 旋转——否决（§1，刷新即失效、治标不治本）。
- 预览页内嵌原图 + 全屏查看器双入口——否决（§2，两套刷新联动，入口翻倍收益微小；点开进全屏即转）。
- 跟随 VISION_AUTO_ROTATE 开关与视觉配置——否决（§3，手动意图被自动功能开关连坐）。
- 每次点击弹确认——否决（§4，连点操作流）。
- files 页文件列表/多选批量旋转——超出「预览期旋转」范围，另立任务。
- 原图备份到 .cortex——不做（与 ADR-0017 同口径：风险可控，误转投诉再补；且 90° 步进转错可再点复原）。

## Consequences

- 新端点 `POST /api/preview/rotate?path=...`（同步 def，threadpool 执行）；`broadcast_rotated` 加 `manual` 参数（默认 False，判向链路零改动）。
- 图像预览 `writable=False` 语义不变（那文本编辑写回闸门）；旋转是独立 mutation 通道，二者并存。
- 前端 `cortex:image-rotated` 事件消费方扩容：app-bar toast（manual 分措辞）+ md-viewer / 日记缩略图刷新匹配原图（cache-bust，防旧方向缓存）。
- 旋转按钮出现意味着「点击会永久改写原图文件」——title 明示「顺时针旋转 90° 并保存」。
