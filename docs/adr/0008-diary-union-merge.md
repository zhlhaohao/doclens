# 日记目录使用 union 合并：ours-wins 的按路径例外

ADR-0006 定了 Git 同步冲突全局偏向本地（ours-wins），远端改动静默消失。但日记年度 md 是多设备**高频追加**文件：两台设备同一天各录片段，auto-commit 后合并必冲突，ours-wins 会静默丢掉其中一端当天的全部片段——这不是小概率事件，是常态化丢数据。

决议：`日记/` 目录通过 `.gitattributes merge=union` 使用 union 合并——冲突时双方追加的行都保留。append-only 结构的文件天然适合 union。ours-wins 仍是全局默认，日记是按路径的显式例外，ADR-0006 本身不变更。

## Consequences

- union 合并不理解 Markdown 小节结构：两台设备各自新建同日小节头时，合并后可能出现重复的小节标题；两端都触发 AI 总结时可能出现两份当日成品。接受此低概率残留（缓解：总结前重读文件确认片段态；重复内容人工删一行即可）。
- `.gitattributes` 需随知识库模板/初始化分发到各机器才生效；既有知识库需补写该文件。
