# 应用主题包（三套内置主题）

Status: accepted

Web UI 新增「主题色切换」，经烤问会话钉死为**完整主题包**（成套预设切换），翻 ADR-0036「否决全应用双主题」时预留的口子（「将来若立项不与本决策冲突」）——代码主题仍独立演进，本决策不触碰其两态语义（同日另行升级为三态，见下）。背景：ADR-0036 当年否决的核心理由（tokens.css 全量双化工程量大、与 Meta 白画布基调冲突）在用户明确立项「主题包」后被接受为代价；Meta 白降级为默认主题而非唯一形态，DESIGN.md 标尺相应放宽为「Meta 白 = 默认主题」。

- **内置三套、不开放自定义**（2026-10-14）：Meta 白（默认，现状收编）/ 深夜（GitHub dark 系深底，沉淀 ADR-0036 代码主题色板基因）/ 暖纸（米黄纸底长阅读护眼）。否决开放式自定义主题注入（主题 schema 设计 + 任意 CSS 值注入排障面不可控）；主题以 CSS 变量表定义，机制上天然可扩展。
- **纯前端实现、零后端**：`localStorage["cortex.theme"]` + `document.documentElement` 的 `data-theme` 属性切换，与代码主题/font-scale 同构的机器级显示偏好（每设备各自记忆，延续惯例）。入口 = 设置页「外观」区块（三选一色卡预览）为主 + app-bar 快捷切换钮。
- **作用边界 = 壳与画布跟随，文件内容原样呈现**：应用壳 + md 预览画布（含 fenced 代码块、diff 中性底、PDF viewer UI 皮、图像周边 UI）跟随；PDF 页面自身、图像原图不碰（文件即真相）；TUI 不动。md fenced 块的跟随与 ADR-0036「不卷入」不冲突——那条约束的是代码主题（局部换肤白底流嵌深色拼图），应用主题下整个阅读流一起换。
- **强调色允许成套校准**：深夜主题可将钴蓝提亮至浅阶变体（同色相 #3c94f7 系，对比度优先——#0064e0 在 #0d1117 上作链接文字 <4.5:1 不达 WCAG AA）；Meta 白/暖纸保持原钴蓝。否决跨色相换品牌色（同一产品三副面孔）。
- **散落颜色一次清理干净**：组件内 30+ 处硬编码 hex / 浅色 fallback 全量 token 化（现状已违反 DESIGN.md「样式只用 tokens.css 变量」，本次还债），并加架构守卫（仿 tests/test_architecture.py 模式，grep 组件 ts 硬编码色）防回归。否决长尾留修（深夜主题可见瑕疵）与只覆盖 tokens 变量（破相半成品）。
- **FOUC 防护**：index.html `<head>` 内联阻塞小脚本先读 localStorage 挂 `data-theme` 再加载应用（业界标准解法）；PWA 已有内联先例，无 CSP 障碍。否决 Lit 首帧挂属性（每次刷新白闪）。
- **Shoelace 延续自映射**：每套主题在自己的 CSS 块内重定义整段 `--sl-*`（与 `--cortex-*` 同块一对一维护），不叠加官方 dark.css（两套暗色体系打架，观感不受控）。
- **实施一次到位、不分期**（用户选择，与推荐的「地基期/主题期」两分法相反）：全量 token 化 + 三套色板 + 代码主题三态升级 + 入口 + FOUC + 守卫一批交付；回滚粒度代价由用户接受。
- **代码主题同步升级三态**：跟随应用主题（新默认，未显式设置=跟随）⇄ 强制浅 ⇄ 强制深，显式设置即固定覆盖。此为 ADR-0036 明文预留的「两态将来加 auto 是兼容扩展」路径落地，不翻其核心案。
