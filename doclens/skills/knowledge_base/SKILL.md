# 知识库技能

## 工具

- **search_kb**: FTS5 全文检索文档片段（自然语言关键词，自动中英文分词）。返回 XML（`<meta>` 含路径/层级 + `<content>`）。**结果用于回答必须加引文**。
- **grep**: 正则搜索文件内容（含未索引文件）。`search_kb` 无结果或需精确匹配（代码/正则模式）时用。结果 `<path>` 可直接传给 `read_document`。
- **read_document**: 读文档完整/部分内容（md/pdf/docx/pptx/xlsx/html/代码等）。**结果用于回答必须加引文**。
- **manage_kb**: 索引管理（`reindex` 重建 / `stats` 统计）。

## ⚠️ 回答铁律（最高优先级）

只要调用了 `search_kb` / `read_document` / `grep` 任一回答用户，回答**必须同时**：

1. **正文标注**：引用处插 `[N]`（如 `[1]`、`[1][2]`），紧跟陈述、标点前。
2. **末尾引文**：追加 `## 参考资料`，每条 `1.` `2.` 编号（**不用 `[N]` 作列表前缀**），内容**只写相对 workdir 的文档路径**（如 `生命科学/xxx.md`）。
   - **格式约束**：路径**禁止** markdown 链接 `[text](url)`、**禁止** `file://` 绝对 URL、不含 `<hierarchy>` / 行号。违反 → 用户点击"打不开"。
   - `search_kb`/`grep` 取 `<path>`；`read_document` 取 `文档:` 行后路径。同一文档只列一次，保持顺序。
   - **只引用答案内容实际来源的 `<result>`**：答案的数据/结论来自哪条命中就引哪条的 `<path>`；与答案无关的命中**禁止罗列**（宁缺毋滥）。正文每个关键论点都必须能在所引文档中找到依据。

用了上述工具却没有 `## 参考资料` = 不合规，补齐再输出。流程性回复（reindex/stats 提示）除外。

**回答前自检**：用了工具？正文有 `[N]`？末尾有 `## 参考资料` 且路径是纯相对路径？同一文档只列一次？

**示例**：
```
量子计算利用量子比特进行信息处理 [1][2]。

## 参考资料
1. 量子计算导论/第一章.md
2. 量子计算导论/第二章.md
```

## 机器解析契约（系统强制）

系统会**机器解析**「## 参考资料」章节并**校验路径是否存在**；不合规时将改用工具检索结果兜底并向用户告警（不再重答）。严格遵循：

1. 章节标题必须正好是 `## 参考资料`（两个#、空格、"参考资料"四字）
2. 每行 `数字. 路径`（如 `1. 量子计算/第一章.md`），数字后一个点一个空格
3. 路径 = 纯相对路径，禁止 `[t](u)` / `file://` / 行号 `:数字` / `<...>`
4. 用了 `search_kb`/`grep`/`read_document` 必须有本章节；路径必须真实存在

## 搜索策略

1. `search_kb` 检索 → 基于结果回答（引用路径）
2. 深度研究：`search_kb` 定位 → `read_document` 读关键章节（`section="第三章 实验方法"` 返回该节及子节点；或 `start_line/end_line` 按行读）→ 必要时 `grep` 补搜
3. 无结果：`manage_kb(action='reindex')` 重建索引后重试

`search_kb` 调用示例：`search_kb(query="机器学习 深度学习", max_results=10)`

### FTS 查询策略（关键）

`search_kb` 是 FTS5 **精确关键词匹配**，非语义检索，单次查询易漏。**必须**：
1. 多种关键词组合多次查询
2. 中文无结果换英文（反之亦然）
3. 同义词/近义词替换
4. 长句切分为短词组合
5. 多次结果去重合并（顺序调即可，本地 FTS 很快）

## 多格式读取

- PDF/DOCX/PPTX/XLSX 等二进制格式**必须用 `read_document`**（非 `read_file`）
- `section` 按章节标题定位（多层嵌套结构完整提取）；`start_line/end_line` 按行读

## 边界（强制）

**仅用于内部知识库问答**。**禁止**：`Task` 子代理（脱离上下文 + 自带外部工具）、`webfetch` / web 搜索 / `bash` 联网。仅用上述 4 个工具在本地作答。无结果告知用户并建议重建索引，**不转向外部搜索**。
