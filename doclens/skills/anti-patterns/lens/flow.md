# anti-patterns 技能流程图

> 附件 D（lens/flow.md）。SKILL.md 全流程的 mermaid 可视化——技能维护者用来校验流程改动后图文一致；审计执行时以 SKILL.md 文字为准，本图仅供快速回忆流程骨架。

## 一、两态协议总览

```mermaid
flowchart TD
    U((用户)) -->|"反模式审计 / 评审 XX / 坏味道清理"| GATE{输入判别}
    U -->|"修 AP-n / 先处理第2条"| EXEC[执行态]
    U -->|"AP-n 是什么问题"| Q["只解释不执行<br/>（追问非下令）"]
    U -->|"讲讲这个项目/模块"| OUT["不触发本技能<br/>→ 口头回答"]

    GATE -->|"未点名台账条目"| AUDIT[审计态 默认]
    AUDIT --> S1[第1步 定范围] --> S2[第2步 判据装载] --> S3[第3步 探索分析] --> S4[第4步 定级 P1-P4] --> S5[第5步 写台账落盘]
    S5 --> WAIT["对话侧给摘要表<br/>⏸ 停，等令"]
    WAIT -.->|"用户下令 AP-n"| EXEC
    WAIT -.->|"用户追问"| Q

    EXEC --> E1[修复 → 回归 → 台账更新 → 提交] --> WAIT
```

**图 1：两态协议——执行权在用户，审计态产出台账后停等令**

## 二、审计态五步（含判据装载与分域并行）

```mermaid
flowchart TD
    A1["第1步 定范围"] --> A1a["点名范围（模块轨/feature轨·用户确认清单）"]
    A1 --> A1b["机械扫描恒全仓：私有 import / 行数 top /<br/>常量多处定义 / as any·裸 fetch 密度 / 架构守卫测试"]
    A1 --> A1c["仓库纪律文档 = 附加判据"]

    A1a & A1b & A1c --> B1["第2步 判据装载"]
    B1 --> B1a["探测技术栈（读 pyproject/package.json，不问用户）"]
    B1a --> B1b{"附件栈小节覆盖?"}
    B1b -->|"命中"| B1c["装载命中的小节，跳过其余"]
    B1b -->|"项目换了栈"| B1d["联网检索新栈清单<br/>→ 重写附件对应节"]
    B1c & B1d --> B1e["复检既有清单（过时就地更新 + 来源 + 日期）"]

    B1e --> C0["第3步 探索分析（分域：先后端，再前端）"]
    C0 --> C1["后端域（含数据库层）"]
    C1 --> C1a["装载 lens/backend.md 命中节 +<br/>lens/general.md 架构/后端节"]
    C1a --> C1b["切组：每组 ≤15 文件·判据 ≤8 条<br/>（大文件 2 倍计权，注意预算=乘积）"]
    C1b --> C1c["并行子代理：每批 ≤6·收齐再派<br/>两遍读法：grep 骨架 → 嫌疑 ±30 行取证"]
    C1c --> C1d{"某组失败/截断?"}
    C1d -->|"是"| C1e["对半缩小补跑；再败 → 主代理直读补齐"] --> C1f
    C1d -->|"否"| C1f["收齐后端域笔记"]
    C1f --> C2["前端域（同构并行协议）"]
    C2 --> C2a["装载 lens/frontend.md 命中节 +<br/>lens/general.md 前端/组件/功能节"]
    C2a --> C2f["收齐前端域笔记"]

    C1f & C2f --> D1["主代理交叉核实：<br/>接口咬合 / 文档-代码冲突 / 合并去重 /<br/>灰色项核实 / 反证归档 P4"]
    D1 --> E1["第4步 定级"]
    E1 --> E1a["P1 正确性安全已损→立即修"]
    E1 --> E1b["P2 健壮性演进受损→近期修"]
    E1 --> E1c["P3 纯代码组织→择机修"]
    E1 --> E1d["P4 记录即处置→文档化/关闭"]
    E1a & E1b & E1c & E1d --> F1["第5步 台账落盘<br/>antipatterns/范围.md<br/>（AP-n 编号 + status + 执行记录）"]
    F1 --> STOP["对话侧摘要表 ⏸ 等令"]
```

**图 2：审计态五步——判据分域装载、子代理双重上限并行清查、证据链进台账**

## 三、子代理单组生命周期（第 3 步内部）

```mermaid
sequenceDiagram
    participant M as 主代理
    participant S1 as 子代理 A（路由组）
    participant S2 as 子代理 B（model 组）
    participant S3 as 子代理 C（前端组件组·下批）

    Note over M: 切组并裁剪判据：路由组附框架层判据、<br/>model 组不附事件循环判据（≤8 条/组）
    M->>S1: prompt = 文件清单(≤15) + 判据A(≤8) + 两遍读法 + 三节返回物
    M->>S2: prompt = 文件清单(≤15) + 判据B(≤8) + …
    Note over S1,S2: 同批 ≤6 并行；grep 骨架 → 嫌疑 ±30 行取证
    S1-->>M: ①候选观察 ②灰色项 ③反证
    S2-->>M: ①候选观察 ②灰色项 ③反证
    Note over M: 收齐本批才派下一批（防 429）
    M->>S3: （后端域收齐后）前端域判据…
    S3-->>M: ①②③
    Note over M: 合并去重（同形态留证据最全）→<br/>灰色项核实 → 反证归 P4 → 定级入台账
```

**图 3：单组子代理生命周期——判据按组裁剪、批间串行、主代理三职责**

## 四、执行态四护栏

```mermaid
flowchart LR
    L["用户下令 AP-n"] --> G1{"护栏1 单条目单提交<br/>（明确说 1、2 一起做除外）"}
    G1 --> FIX["按台账方案修复"]
    FIX --> G2{"护栏2 分层回归<br/>项目分层回归约定 + 守卫测试<br/>前端必 build / 后端按需重启"}
    G2 -->|"不过"| FIX
    G2 -->|"过"| G3{"修复中发现新问题?"}
    G3 -->|"是"| G4["护栏3 追加新条目 discovered-during-fix<br/>不顺手修，继续原条目"] --> G5
    G3 -->|"否"| G5{"护栏4 方案偏离?<br/>误判/契约变更/影响面扩大"}
    G5 -->|"是"| STOP2["⏸ 暂停 → 呈差异 → 用户确认"] --> G5
    G5 -->|"否"| DONE["台账 status→done(commit)<br/>提交（message 引用 AP-n）"]
```

**图 4：执行态四护栏——单条目单提交、分层回归、新问题不扩散、偏离即停**

## 五、台账数据流

```mermaid
flowchart LR
    LENS["附件 B/C 栈清单<br/>lens/backend·frontend.md"] -->|审计装载| AUDIT2["审计态"]
    GEN["附件 A 通用透镜<br/>lens/general.md"] -->|兜底归类| AUDIT2
    AUDIT2 -->|发现 AP-n·P1-P4| LEDGER[("台账<br/>antipatterns/范围.md")]
    LEDGER -->|下令引用 AP-n| EXEC2["执行态"]
    EXEC2 -->|status: done commit| LEDGER
    EXEC2 -->|新问题 discovered-during-fix| LEDGER
    LEDGER -->|新型态多次实证| GEN
```

**图 5：台账数据流——附件判据 ↔ 审计 ↔ 台账 ↔ 执行的闭环，新型态可晋升回通用透镜**
